The Role

A penetration tester is an ethical hacker who is given permission to attack a company's systems. Within an agreed scope, they look for weaknesses in networks, web apps and APIs, safely exploit them to show the real impact, and write a clear report on how to fix them.

terminal

Required Skills

Good networking knowledge (TCP/IP, common services, Active Directory), Linux and Windows basics, web app security (OWASP Top 10) and tools like Nmap, Burp Suite and Metasploit. On top of that, Python or Bash scripting, following a proper methodology (PTES, OWASP WSTG) and writing clear reports.

memory

Modern Relevance

Scanners can pick up known CVEs, but they usually miss business logic bugs, weak access control and small issues that can be chained into a bigger attack. A human tester shows what an attacker can really do. With the Cyber Security Act 2024 now in force in Malaysia, organisations running critical systems have more reason to get their security tested.
